# Hola, soy Jesús María 👋

**Senior Backend Developer** · Full Stack · Forward Deployed Engineer · Alcorcón, Madrid

Backend con Node.js y TypeScript en sistemas de pago, control de accesos y vending: integraciones

requisito, no mejora.
